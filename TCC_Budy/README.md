# TCC Budy

Dossier de travail GitHub pour le projet Pyto **TCC Budy**.

Le projet complet est stocké dans `TCC_Budy/TCC Budy.zip` afin de conserver l’arborescence Pyto telle qu’elle a été transmise.

## Installation dans Pyto

1. Télécharger `TCC Budy.zip`.
2. Décompresser l’archive dans `iCloud Drive/Pyto/`.
3. Vérifier le chemin `iCloud Drive/Pyto/TCC Budy/app.py`.
4. Lancer `app.py` dans Pyto.

## Confidentialité

Ne jamais ajouter au dépôt :

- clé API OpenAI ;
- base SQLite personnelle ;
- journaux contenant des données sensibles ;
- exports de conversations personnelles.
