# Installation dans Pyto

1. Télécharger le dossier `Pyto_App_Framework_V6_20260726_120539` depuis GitHub.
2. Copier le dossier `projet` dans iCloud Drive ou dans le dossier local de Pyto.
3. Conserver ensemble les quatre fichiers Python et le dossier `ui`.
4. Ouvrir `projet/main.py` dans Pyto.
5. Appuyer sur Exécuter.

## Lancement depuis Raccourcis

Créer un raccourci iOS avec l’action Pyto **Run Script**, puis sélectionner `main.py`. Le raccourci peut ensuite être ajouté à l’écran d’accueil.

## Diagnostic

En cas d’erreur :

- vérifier que `ui/index.html`, `ui/app.css` et `ui/app.js` existent ;
- vérifier que le projet n’a pas été séparé en plusieurs dossiers ;
- exécuter uniquement `main.py` ;
- consulter la console Pyto pour la trace complète.
