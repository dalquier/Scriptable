# Installation

1. Mettre à jour le dépôt dans Working Copy.
2. Copier le dossier `projet` dans un dossier Pyto conservant tous les modules ensemble.
3. Ouvrir `app.py` dans Pyto.
4. Lancer le script.
5. Lors du premier lancement, utiliser `Continuer avec Apple` si l’application indique que la session n’est pas connectée.
6. Revenir ensuite dans l’application, coller un lien `https://chatgpt.com/s/...` et toucher `Analyser`.

Les réglages sont enregistrés dans `~/Documents/CodexReaderV7/settings.json`.
