# Installation

1. Mettre à jour le dépôt dans Working Copy.
2. Copier tout le dossier `projet` dans Pyto iCloud.
3. Ouvrir `app.py`.
4. Lancer le script.
5. Se connecter avec Apple si nécessaire.
6. Coller le lien Codex et toucher `Charger`.
7. Essayer `Analyse auto`.
8. En cas d’échec, toucher `Créer diagnostic` puis `Mode manuel`.
9. En mode manuel, toucher l’encadré gris de la question, puis la zone contenant les deux pouces.
10. Toucher `Extraire manuel`.

Les diagnostics sont enregistrés dans `Documents/CodexReaderDebug/Diagnostics/`.
