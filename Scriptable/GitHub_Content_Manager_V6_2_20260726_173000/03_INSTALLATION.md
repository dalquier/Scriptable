# Installation

1. Télécharger le dossier `projet` complet.
2. Conserver les cinq fichiers dans le même dossier iCloud/Pyto.
3. Ouvrir `main.py` dans Pyto.
4. Exécuter le script.
5. Appuyer sur `Actualiser`.

Les réglages initiaux sont déjà intégrés. Ils restent modifiables et sont enregistrés dans `github_manager_v6_2.local.json`, créé localement à côté des scripts.

Sans jeton, la consultation du dépôt public fonctionne. Les opérations d’écriture exigent un Personal Access Token GitHub autorisé sur le dépôt avec `Contents: Read and write`.
