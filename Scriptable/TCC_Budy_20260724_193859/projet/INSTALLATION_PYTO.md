# Installation Pyto

1. Dans Working Copy, clonez ou mettez à jour `dalquier/Scriptable`.
2. Ouvrez la livraison `Scriptable/TCC_Budy_20260724_193859/projet/`.
3. Copiez le dossier `projet` vers `iCloud Drive/Pyto/TCC Budy`.
4. Ne copiez jamais de clé API dans GitHub.
5. Ouvrez `app.py` dans Pyto puis exécutez-le.

Les dossiers `data/` et `logs/` seront créés automatiquement au premier lancement.
