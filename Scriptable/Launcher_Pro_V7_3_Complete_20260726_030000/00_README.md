# Launcher Pro V7.3 — Livraison complète

Launcher Pro permet de gérer et lancer :

- des scripts Python autonomes ;
- des projets Pyto complets avec un dossier racine et un point d’entrée.

## Point d’entrée

`projet/LauncherPro.py`

## Installation rapide

1. Télécharger le dossier `projet`.
2. Le copier intégralement dans Pyto/iCloud Drive.
3. Exécuter `projet/install.py`.
4. Lancer `projet/LauncherPro.py`.

Cette livraison est autonome et ne dépend pas des anciennes V5, V6 ou V7.
