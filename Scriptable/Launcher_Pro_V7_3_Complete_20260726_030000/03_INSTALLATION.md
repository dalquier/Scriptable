# Installation

1. Télécharger le dossier `projet` complet depuis GitHub.
2. Ne pas séparer les fichiers `LauncherPro.py`, `core/`, `ui/` et `data/`.
3. Ouvrir `install.py` dans Pyto et l’exécuter une fois.
4. Ouvrir ensuite `LauncherPro.py`.
5. Pour conserver un ancien registre, remplacer uniquement `projet/data/registry.json` et les dossiers `data/scripts` / `data/projects` après sauvegarde.

## Widget

Ouvrir `launcher_widget.py` dans Pyto, l’exécuter une fois, puis sélectionner ce script dans un widget Pyto iOS.
