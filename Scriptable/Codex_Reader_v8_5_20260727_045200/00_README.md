# Codex Reader v8.5

Correction du cas où un long tableau ou une liste de fichiers précède la barre des pouces.

## Changements

- défilement automatique jusqu’en bas avant extraction ;
- recherche des pouces dans tout le DOM, même hors écran ;
- utilisation du compositeur « Demander des modifications… » comme borne de secours ;
- extraction de tout le contenu compris entre la dernière question et cette borne ;
- conservation des tableaux dans la vue de résultat ;
- nettoyage des contrôles interactifs sans supprimer leur texte utile.

Copier tous les fichiers du dossier `projet/` dans un même dossier Pyto et lancer `app.py`.
