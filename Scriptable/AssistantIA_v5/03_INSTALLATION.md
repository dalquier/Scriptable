# Installation dans Pyto

1. Récupérer le dossier `Scriptable/AssistantIA_v5` depuis GitHub avec Working Copy.
2. Copier le dossier `projet` dans un emplacement local ou iCloud accessible à Pyto.
3. Dupliquer `config_local.example.py` sous le nom `config_local.py`.
4. Renseigner la clé OpenAI dans `config_local.py`.
5. Exécuter `diagnostic.py`.
6. Exécuter `main.py`.

## Configuration privée

Le fichier `config_local.py` ne doit jamais être envoyé dans GitHub.
