# Installation

1. Dans Working Copy, effectuer un Pull du dépôt `dalquier/Scriptable`.
2. Ouvrir `Scriptable/Codex_Reader_v8_20260727_030317/projet/`.
3. Copier tout le dossier `projet` dans le dossier Pyto d’iCloud.
4. Ouvrir `app.py` dans Pyto.
5. Exécuter le script.
6. Lors du premier lancement, utiliser **Continuer avec Apple** si la session n’est pas reconnue.
7. Coller un lien ChatGPT/Codex partagé, puis toucher **Analyser**.

## Diagnostic

Exécuter `diagnostics.py` si l’analyse JavaScript échoue. La méthode attendue est `evaluate_js`.
