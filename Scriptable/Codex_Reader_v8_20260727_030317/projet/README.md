# Projet Pyto

Lancer `app.py`.

La v8 utilise exclusivement `WebView.evaluate_js` pour lire le DOM de la page authentifiée.

## Utilisation

- Se connecter avec Apple uniquement si le statut l’exige.
- Coller le lien ChatGPT/Codex.
- Toucher **Analyser**.
- Copier la question ou la réponse depuis la vue de résultat.

Les réglages sont enregistrés dans `Documents/CodexReaderV8/settings.json`.
