# GitHub Content Manager V5

Gestionnaire de contenu GitHub conçu pour Pyto sur iPhone/iPad.

## Objectif

Cette application permet de gérer le contenu d'un dépôt GitHub depuis une interface mobile moderne :

- parcourir les fichiers et dossiers ;
- consulter les fichiers texte ;
- créer un fichier ou un dossier ;
- modifier un fichier ;
- renommer un fichier ;
- supprimer un fichier ;
- rechercher un élément ;
- mémoriser plusieurs dépôts ;
- conserver un journal local des actions.

## Dépôt par défaut

- Dépôt : `dalquier/Scriptable`
- Branche : `main`
- Dossier initial : `Scriptable/`

## Sécurité

Le jeton GitHub est stocké localement dans le trousseau iOS via `keyring` lorsque ce module est disponible. Il n'est jamais écrit dans les fichiers du projet.

## Lancement

Ouvrir `projet/main.py` dans Pyto puis exécuter le script.
