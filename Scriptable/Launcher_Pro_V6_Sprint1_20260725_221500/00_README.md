# Launcher Pro V6 — Sprint 1

Sprint 1 fournit le moteur fonctionnel de Launcher Pro pour Pyto sur iPhone/iPad.

## Inclus

- registre persistant des scripts ;
- import d'un fichier `.py` ;
- copie locale sécurisée ;
- exécution isolée avec restauration de l'environnement ;
- historique d'exécution ;
- journalisation ;
- sauvegardes automatiques du registre ;
- paramètres séparés ;
- script de test console.

## Installation rapide

1. Télécharge le dossier `projet` dans Pyto.
2. Place tous les fichiers en conservant l'arborescence.
3. Exécute `install.py` une fois.
4. Exécute `test_sprint1.py`.
5. Exécute ensuite `LauncherPro.py`.

Ce Sprint 1 privilégie la robustesse du moteur. L'interface avancée arrivera au Sprint 2.
