# AssistantIA v6

Client IA pour Pyto avec interface repensée, historique local et pièces jointes.

## Fonctionnalités

- historique des conversations ;
- recherche dans l’historique ;
- pièces jointes locales ;
- interface structurée en modules ;
- recherche Web activable ;
- stockage SQLite ;
- compatibilité Pyto sur iPhone.

## Lancement

1. Copier `config_local.example.py` vers `config_local.py`.
2. Renseigner la clé OpenAI.
3. Lancer `main.py`.
