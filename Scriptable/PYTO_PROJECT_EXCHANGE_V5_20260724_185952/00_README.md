# PYTO_PROJECT_EXCHANGE V5

Livraison initiale créée directement dans GitHub.

Cette livraison contient une base exécutable et structurée du protocole V5, conçue pour rester proche de la V3 tout en ajoutant :

- identifiant de projet ;
- snapshots ;
- modes FULL et DELTA ;
- validation SHA-256 ;
- manifestes enrichis ;
- livraison multi-parties ;
- reprise sur plusieurs réponses ;
- import et export transactionnels.

## Dossier principal

`projet/`

## Lancement dans Pyto

Ouvrir puis exécuter :

`projet/Pyto_Project_Exchange_v5.py`

## Statut

Version initiale fonctionnelle. Elle privilégie la compatibilité avec Pyto et la simplicité de maintenance plutôt qu'une architecture SDK surdimensionnée.
