# Installation

1. Ouvrir le dépôt `dalquier/Scriptable` dans l'application GitHub ou dans Safari.
2. Ouvrir le dossier `Scriptable/PYTO_PROJECT_EXCHANGE_V5_20260724_185952/projet/`.
3. Télécharger `Pyto_Project_Exchange_v5.py`.
4. Enregistrer le fichier dans Pyto.
5. Exécuter le script.

## Utilisation

- **Exporter FULL** : sélectionne un dossier de projet et produit un lot complet.
- **Exporter DELTA** : compare le projet à un snapshot précédent et produit seulement les changements.
- **Importer** : sélectionne un dossier contenant `00_INDEX.md` et les `PART_xxx.md`.
- **Copier le prompt** : place dans le presse-papiers les instructions à envoyer dans une conversation ChatGPT.

## Compatibilité

- iPhone / iPad avec Pyto ;
- Python 3 fourni par Pyto ;
- aucune dépendance externe obligatoire.
