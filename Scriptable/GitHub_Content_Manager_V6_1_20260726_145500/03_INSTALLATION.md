# Installation

1. Télécharger le dossier `projet` dans iCloud Drive ou Pyto.
2. Conserver tous les fichiers Python dans le même dossier.
3. Ouvrir `main.py` dans Pyto.
4. Exécuter le script.
5. Les valeurs initiales sont déjà préremplies.
6. Pour modifier le dépôt, la branche, le dossier racine ou le jeton, utiliser la section Réglages puis le bouton Enregistrer les réglages.

## Jeton

Sans jeton, la lecture du dépôt public reste possible. Les opérations d’écriture nécessitent un Personal Access Token GitHub avec l’autorisation `Contents: Read and write`.
