# Installation dans Pyto

1. Dans Working Copy, effectuer un Pull du dépôt `dalquier/Scriptable`.
2. Ouvrir `Scriptable/Codex_Reader_v9_20260727_052238/projet/`.
3. Copier les cinq fichiers dans un même dossier du stockage Pyto/iCloud.
4. Ouvrir `app.py` dans Pyto.
5. Exécuter le script.
6. Utiliser **Se connecter** si la WebView n’a plus de session ChatGPT active.
7. Coller un lien `https://chatgpt.com/s/...` puis toucher **Analyser**.

## Mode de secours

Si l’analyse automatique ne choisit pas la bonne question :

1. toucher **Choisir la question** ;
2. toucher directement l’encadré gris dans la page Codex ;
3. revenir aux commandes et toucher **Extraire le choix**.

La session dépend des cookies conservés par la WebView Pyto. Le script ne stocke aucun identifiant Apple.
