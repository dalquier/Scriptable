# Developer OS

Developer OS est le noyau d’orchestration destiné à piloter des projets logiciels assistés par IA.

## Sprint 0

Cette première base fournit :

- un Kernel minimal ;
- un registre de services ;
- un bus d’événements ;
- un chargeur de plugins ;
- une configuration centralisée ;
- une journalisation simple ;
- une CLI minimale.

## Lancement

```bash
python -m apps.launcher.main
```

ou depuis la racine du projet :

```bash
python main.py
```
