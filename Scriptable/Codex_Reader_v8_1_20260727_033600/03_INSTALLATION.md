# Installation

1. Faire un Pull du dépôt dans Working Copy.
2. Ouvrir `Scriptable/Codex_Reader_v8_1_20260727_033600/projet/`.
3. Copier tout le dossier `projet` dans le dossier Pyto d’iCloud.
4. Ouvrir `app.py` dans Pyto.
5. Lancer le script.
6. Se connecter avec Apple si le statut le demande.
7. Coller le lien Codex puis toucher **Analyser**.

La session dépend des cookies conservés par la WebView de Pyto. Aucun mot de passe n’est enregistré par le projet.
